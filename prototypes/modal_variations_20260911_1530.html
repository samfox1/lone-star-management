The system (applies to every modal)
Sizes

S 480 confirm / add one thing
M 640 edit one item
L 880 item with a list or two columns
28px padding · 16px radius · no inner scroll under 88vh

Header

Title = the thing's name, not "Edit date"
mono meta line under it (date · place · one stat)
× top-right, Esc, click-out

Fields

label above, mono caps 10px
underline only, ink on focus
grid 2–3 across, never stacked boxes
secondary fields fold behind + or read "—"
autosave on blur, no Save button

Lists & footer

rows with hover tools, click to expand
section = mono label + hairline + count
footer: Delete left · Done right, hairline above
flags are pills, never checkboxes in a column
