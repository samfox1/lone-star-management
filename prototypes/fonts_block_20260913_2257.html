Slots as rows. PRIMARY FONT, SECONDARY FONT, CUSTOM 1–3 — each shows the font it holds, set in that font, with the site's own dropdown to change it (every uploaded font, and none). FONTS is the library: name in its face, format, which slots it holds, the bin; + Font is the site's button. Clicking a font's name opens the specimen drawn behind: the name and format, a headline, the alphabet and numerals, a paragraph, all in the face — with Remove and Save in the footer.
