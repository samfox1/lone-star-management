# Archive

Finished plans and closed reviews. Each one describes work that has shipped, or a
review whose findings are all fixed — kept as the record of why things are the way
they are, not as instructions for what to build next.

Tests and code cite these by NAME (e.g. "ANALYTICS_PAGE_PLAN.md step 4"), never by
path, so moving a file here does not break a citation. `git log --follow` finds a
file's history if it moved before it landed here.

Live plans — anything still describing work in progress — stay at the repo root.
